# Founder Cities

Where should a solo founder live? 49 cities ranked for independent builders.

Opinionated. No ads. No tracking. One HTML file, no backend.

## What it ranks

- **Visa path** — can you actually stay there?
- **Corporate tax** — matters more than personal for founders
- **Personal tax range** — top marginal rate used in scoring
- **Talent density** — depth of local engineering + business talent
- **Cost of living** — monthly solo-liveable budget (USD)
- **Internet** — median Mbps
- **Community** — builder scene + events
- **Climate** — year-round comfort
- **Flight hub** — direct-flight access
- **English** — how far you get without the local language

## Builder Score formula

Weighted blend normalised to 0–100:

| Dimension | Weight |
|---|---:|
| Visa | 18 % |
| Talent | 12 % |
| Corporate tax | 12 % |
| Flight hub | 10 % |
| English | 10 % |
| Cost | 10 % |
| Community | 8 % |
| Internet | 8 % |
| Climate | 6 % |
| Personal tax | 6 % |

## Opinions baked in

- Zero-tax regimes (Dubai, Estonia 0 % retained, Georgia 1 %) rise fast
- US cities rank high on talent but drop on tax + visa pain
- Visa hard = -16 points vs easy, enough to dethrone any city
- Short term lifestyle cities (Bali, Chiang Mai) drop because of thin talent pools
- Dublin's famous 12.5 % corporate rate is reflected
